股市筆記

記錄每一次交易，建立屬於自己的投資紀律。

每一筆交易，都值得被記錄

股市筆記是一款簡單易用的股票交易紀錄工具。 幫助你整理買進、賣出、持股成本與歷史損益， 讓投資決策不再只依靠記憶。

主要功能

✓ 記錄股票買進與賣出

✓ 自動計算持股成本與已實現損益

✓ 分開統計累積獲利與虧損

✓ 查詢每日、每週、每月及每年交易紀錄

✓ 記錄交易原因與投資策略

✓ 分析歷史交易表現

✓ 支援台幣與美元分開記帳

適合哪些人？

適合希望整理股票交易紀錄、 了解自身投資習慣， 並逐步建立交易紀律的使用者。

投資風險提醒

投資有風險，有賺也有賠。 本 App 僅提供交易紀錄與歷史數據分析， 不提供投資建議、股票推薦或收益保證。
